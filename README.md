# PCL2-
PCL2修复原版下载功能


使用方法

1.下载解压
2.点击一键恢复下载
3.完事了
4.还原原版会回滚之前所作的操作
5.(可选) 打开哔哩哔哩去看一部宇宙霹雳超级无敌传世巨作Ave Mujica



Windows 10/11 通常已经具备所需的 Windows PowerShell 5.1 与 .NET Framework。工具在 BAT 内自带处理组件，运行时不需要 Python、开发工具或联网下载依赖。文件夹需要允许当前用户写入。

 恢复的功能

龙猫删了啥就能恢复啥

可选命令

在脚本所在目录打开命令提示符，可使用：

```bat
PCL2-一键恢复下载.bat "任意目录\Plain Craft Launcher 2.exe"
PCL2-一键恢复下载.bat /check "任意目录\Plain Craft Launcher 2.exe"
PCL2-一键恢复下载.bat /restore "任意目录\Plain Craft Launcher 2.exe"
```

`/check` 只在临时目录生成并验证补丁，不替换启动器。

如果未来更新替换了 EXE，不保证本脚本适用于新版本；版本或结构不匹配时会停止，不会自动降级。
